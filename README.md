# Projet 3 column cards from Front End Mentor

Ce projet est proposé par Front End Mentor, site qui met à disposition des challenges de différents types pour s'entraîner à coder et intégrer des maquettes.

## Le cadre du projet

L'objectif est de reproduire trois colonnes, presque identiques (mais avec de petits détails qui varient d'une carte à l'autre), comme on peut en voir sur de nombreux sites. Dans le contexte, on imagine être sur un site de vente ou de location de véhicules qui propose trois cartes en lien avec différents modèles "Sedans", "SUV" et "Luxury Cars" avec à chaque fois une présentation brève et un bouton pour un savoir plus.

Les contenus (assets, styles, titres) sont fournis.
